# Squoosh Pro 0.3.0

Windows 界面重新设计，同时改进 Windows 和 macOS 的图片对比预览。

## 这次更新

- 新的 Windows 工作台：左侧图片列表、中间效果预览、右侧压缩设置；小窗口自动切换为分区导航。
- 工具栏直接显示“添加图片”“添加文件夹”和“开始压缩”，整块按钮均可点击。
- 预览画面中增加清晰的分界线和拖动手柄，左侧为原图，右侧为输出。
- 支持“适应窗口”、真实的“100%”像素查看、放大、缩小和放大后的画面拖动。
- 修复窗口大小反复变化时的界面崩溃、预览状态更新和部分设置操作问题。
- 预览完成的结果会显示“已缓存”，导出时复用相同设置的结果；缓存有容量限制，并在任务结束时清理。
- 保存个人预设时可填写名称和备注；高级选项可以点击“说明”查看解释。
- 保留严格的 KB 上限检查、原图保护和带时间戳的结果目录。

## 下载哪个文件

| 电脑 | 下载文件 |
| --- | --- |
| 64 位 Windows 10 或 Windows 11 | `Squoosh-Pro-0.3.0-Windows-x64.zip` |
| Apple 芯片或 Intel Mac，macOS 13 及以上 | `Squoosh-Pro-0.3.0-macOS-universal.zip` |

Windows：全部解压后运行 `SquooshPro.exe`，请保留完整文件夹。运行组件已经包含在下载包中，不需要另装 .NET。

macOS：解压后将 `Squoosh Pro.app` 放入“应用程序”。

## 每张不超过 150 KB

选择“网页 JPEG ≤150KB”预设。这里的 150 KB 是 150,000 字节，应用会在允许的尺寸和质量范围内寻找尽量清晰的结果；无法达到上限时会明确显示失败，不会将超限图片当作成功结果。
