# Squoosh Pro 0.3.1

## 新增统一应用图标

Squoosh Pro 现在有了蓝绿色的图片卡片图标，便于在桌面和系统中识别。

- macOS：应用文件、Finder、Dock 和应用切换中使用新图标。
- Windows 10 / 11：程序文件、桌面快捷方式、任务栏、窗口切换和标题栏使用同一套图标。
- 为小图标、常见显示缩放比例和 Retina 屏幕提供多尺寸资源。

本次更新不改变压缩设置、个人预设、历史记录或原图，也保留 0.3.0 的图片对比预览和自适应工作区。

## 下载

| 系统 | 文件 |
| --- | --- |
| Windows 10 / 11，64 位 x64 | `Squoosh-Pro-0.3.1-Windows-x64.zip` |
| macOS 13 及以上，Apple 芯片 / Intel | `Squoosh-Pro-0.3.1-macOS-universal.zip` |

Windows 请完整解压后启动 `SquooshPro.exe`，不要单独移动 EXE 或删除 `Assets` 文件夹。需要桌面入口时，可以为新版 `SquooshPro.exe` 创建快捷方式。macOS 解压后将应用放入“应用程序”。

旧快捷方式仍会指向旧版本，请更新其目标或为新版创建快捷方式。如果系统短暂显示旧图标，可关闭并重新启动新版应用，或重新创建该快捷方式；不需要关闭系统防护或清空系统图标缓存。

每个平台均附带 `.sha256` 校验文件、中文使用说明和第三方许可公告。当前 Windows 版本未进行商业 Authenticode 签名；macOS 版本使用临时签名，未进行 Developer ID 签名或 Apple 公证。请只从本仓库下载，不要关闭系统安全检查。
