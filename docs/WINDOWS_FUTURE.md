# Future Windows Foundation

- UI: WinUI 3 with Windows App SDK
- Language: C# and XAML
- Codec host: WebView2 adapter or a future native codec host
- Shared components: `shared/codec-worker`, JSON Schema contracts, presets, and golden-test metrics
- Target: Windows 10 version 1809 or newer and Windows 11

The macOS application does not include .NET, WinUI, Windows build dependencies, placeholder Windows pages, or path assumptions. A Windows implementation should map its native file authorization and atomic commit rules to the same request, response, preset, and report semantics.
