# Squoosh Pro 0.2.0 Beta 1 发布说明

这是首个 Windows 公开测试版，同时保留现有 macOS 版本。

## 新增

- 原生 WinUI 3 图形界面，支持 Windows 10 和 Windows 11 x64。
- JPEG（JPG）、PNG、WebP 和 AVIF 本地压缩。
- “网页 JPEG ≤150KB”严格大小预设：每张图片不超过 150000 字节，并自动尝试 1000、960、920 像素宽度。
- 多图片和文件夹导入、拖放、图片搜索、点击预览与前后对比滑杆。
- 有边界的预览缓存；预览结果可直接复用于正式导出。
- 用户预设名称、备注、导入与导出。
- 硬件加速预览开关和启动异常后的自动兼容回退。
- 时间戳输出目录、源文件指纹检查、临时文件验证、同名文件自动改名。
- 暂停、继续、取消、失败项重试和本地历史记录。

## 兼容性与测试

- Windows 10 测试环境：10.0.19045.6456，x64。
- Windows 11 测试环境：10.0.26200.9457，x64。
- 两台系统均完成真实 WinUI 内部渲染检查，覆盖工作区、压缩设置、920×680 紧凑窗口、应用设置和完成状态。
- 两台系统均完成搜索、预览滑杆、设置控件、高级选项说明弹出、预设保存入口、硬件加速默认状态和开始压缩操作；920×680 窄窗口下侧栏自动收起，预览标签完整可见。
- 同一生成测试图在两台系统上均输出 142019 字节、999×636 的 JPEG，满足 150000 字节上限；源文件 SHA-256 保持不变。
- Windows 核心检查覆盖四种输出格式、比例缩放、不放大、严格 150 KB、原图保护、同名改名、原子提交和缓存边界。

## 下载与启动

下载 “Squoosh-Pro-0.2.0-Windows-x64.zip”，执行“全部解压”，然后运行文件夹中的 “SquooshPro.exe”。必须保留完整文件夹，不能只复制 EXE。

当前 Beta 尚未进行商业代码签名，SmartScreen 可能显示提醒。请只从项目 GitHub Release 下载，先核对 “.sha256”，再决定是否运行。不要关闭 Windows Defender。

完整操作方法见 “USER_GUIDE_WINDOWS_ZH.md”。

## 已知限制

- 仅提供 Windows x64 版本，不包含 Windows ARM64 或 32 位版本。
- Windows 发布包尚未进行 Authenticode 代码签名。
- 动图压缩、裁切、滤镜、云同步、账户和自动更新不在本版本范围内。
- macOS 发布包仍是独立的 0.1.0 Beta 1，本次未重新签名或重新发布 macOS 安装包。
