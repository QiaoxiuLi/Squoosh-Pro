# Squoosh Pro Windows 普通用户使用说明

Squoosh Pro 是一款在 Windows 本地运行的批量图片压缩工具。图片不会上传到服务器，原图不会被覆盖。每次压缩都会创建一个带时间的 “result_年月日_时分秒” 文件夹。

## 系统要求

- 64 位 Windows 10 或 Windows 11
- 本版本仅提供 x64 安装包，不支持 Windows on ARM 原生运行
- 建议预留至少 1 GB 可用磁盘空间用于解压和保存结果

当前 Beta 安装包尚未进行商业代码签名，Windows Defender SmartScreen 可能在第一次运行时显示提醒。请只从本项目的 GitHub Release 页面下载，并先核对 SHA-256。

## 下载和启动

1. 下载 “Squoosh-Pro-0.2.0-Windows-x64.zip” 和同名 “.sha256” 文件。
2. 右键 ZIP，选择“全部解压”。不要只把 “SquooshPro.exe” 单独拖出来，程序需要同一文件夹里的运行文件。
3. 双击解压后文件夹中的 “SquooshPro.exe”。
4. 如果 SmartScreen 出现提醒，请先确认下载地址和 SHA-256；确认无误后选择“更多信息”，再选择“仍要运行”。

不需要安装 .NET、ImageMagick 或 Windows App SDK。发布包已经包含运行所需组件。不要关闭 Windows Defender，也不要从第三方下载站获取本软件。

## 最快使用方法

1. 启动 Squoosh Pro。
2. 在首页选择一个压缩方案。
3. 点击“选择图片”或“选择文件夹”，也可以把图片拖入窗口。
4. 在左侧图片列表中点击图片，查看原图和输出效果；拖动“原图 / 输出对比”滑杆检查细节。
5. 如有需要，打开“压缩设置”调整格式、质量、KB 上限和图片尺寸。
6. 点击右上角“开始压缩”。
7. 完成后点击“打开输出目录”。

## 如何选择压缩方案

### 智能推荐

普通照片输出 JPEG，带透明区域的图片输出 PNG，并把最长边限制为 1920 像素。

### JPEG（JPG）

适合照片、商品图和大多数网站图片。JPEG 可在 Chrome、Edge、Firefox、Safari、Android 和 iPhone 的主流浏览器及应用中打开。JPEG 不支持透明背景，透明区域会填充为白色。

### 网页 JPEG ≤150KB

适合网站要求每张图片不超过 150 KB 的情况：

- 1 KB 按 1000 字节计算。
- 每张图片最终不得超过 150000 字节。
- 应用会尝试 1000、960、920 像素宽度，并在每个宽度下寻找尽量高的 JPEG 质量。
- 小图片不会被放大。
- 如果最低质量和允许尺寸仍无法满足限制，该图片会明确显示失败，不会把超限文件标记为成功。

### 无损 PNG

适合截图、图标、文字较多的图片和透明背景。文件通常比 JPEG 大。

### 现代网站 WebP

适合现代网站并支持透明背景。发布前应确认目标平台接受 WebP。

### 极致压缩 AVIF

通常可以进一步减小文件，但编码速度较慢，部分旧软件不支持。兼容性优先时请选择 JPEG（JPG）。

## 常用设置

### 指定质量

质量越高，图片通常越清晰，文件也越大。照片可以先使用 75 到 85，再通过预览确认。

### 每张不超过指定大小

输入单位是 KB。上限对每张图片单独计算，不是整批图片的平均值。

### 图片尺寸

- “保持原尺寸”：不主动改变尺寸。
- “最长边”：横图和竖图都以最长一边为上限。
- “固定宽度”：按指定宽度等比例缩放。
- “固定高度”：按指定高度等比例缩放。
- “适合指定范围”：完整保留图片，不裁切，宽和高都不会超过设置范围。
- “自动选择宽度”：从预设宽度中选择满足大小限制的最大宽度。
- “小图片保持原尺寸”：尺寸已较小的图片不会被放大。

### JPEG 高级设置

- “渐进式显示”：网页加载时先显示整张粗略图片，再逐渐变清晰；主流浏览器支持。
- “优化文件大小”：优化 JPEG 内部编码，通常能减小文件，但压缩时间可能稍长。
- “标准兼容模式”：输出 Baseline JPEG，主要用于非常老旧的软件。

高级设置展开或收起只改变界面显示，已经选择的选项始终生效。

## 预览、搜索和缓存

- 使用图片列表顶部的搜索框按文件名查找图片。
- 点击图片即可切换预览对象。
- 预览完成后，列表会显示“已缓存”。原图和设置没有变化时，正式导出会复用该结果。
- 修改压缩设置后会重新计算，不会错误复用旧预览。
- 缓存最多保留 24 项或 128 MB，完成任务、清空列表或退出应用时会清理。

## 硬件加速预览

“设置”中的“硬件加速预览”默认开启。WinUI 会使用 Windows 的系统图形管线显示和缩放预览。如果上次启动在预览初始化前异常结束，应用会在下次启动时自动关闭该选项。此设置只影响预览，不改变输出文件。

## 保存自己的预设

1. 在“压缩设置”中完成调整。
2. 点击“保存为预设”。
3. 输入名称，并可填写用途备注。
4. 以后可以在预设列表中直接选择。

“导出我的预设”只会导出用户保存的预设，不包含软件自带预设。

## 输出与文件安全

- 所有图片在本机处理。
- 应用不会覆盖或删除原图。
- 输出先写入临时文件，经过格式、尺寸、解码和大小检查后才保存为最终文件。
- 同名文件已经存在时会自动使用新文件名。
- 默认输出目录包含时间戳，重复运行不会覆盖以前的结果。
- 设置、预设和历史记录保存在 “%LOCALAPPDATA%\Squoosh Pro”。

## 校验下载文件

在下载目录打开 PowerShell，运行：

    Get-FileHash .\Squoosh-Pro-0.2.0-Windows-x64.zip -Algorithm SHA256

显示的哈希值应与 “.sha256” 文件中的值完全一致。

## 常见问题

### SmartScreen 阻止启动

先确认文件来自本项目 GitHub Release，并核对 SHA-256。确认无误后使用“更多信息”中的“仍要运行”。不要关闭整个 Windows 安全中心。

### 双击后提示缺少文件

请重新执行“全部解压”，并保留整个文件夹。不能只复制 “SquooshPro.exe”。

### 为什么某张图片没有达到目标大小

应用设置了最低质量和允许尺寸，避免输出不可用图片。如果仍无法满足目标，会显示失败。可以提高 KB 上限、允许更小尺寸，或改用 WebP/AVIF。

### 为什么预览大小和导出大小有时不同

原图和设置不变时会复用已缓存预览。修改格式、质量、尺寸或高级设置后会重新计算，大小也会变化。

### 是否支持 Windows 7、32 位 Windows 或 ARM64

不支持。当前发布包只面向 64 位 Windows 10 和 Windows 11。
