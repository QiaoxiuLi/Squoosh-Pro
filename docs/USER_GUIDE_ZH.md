# Squoosh Pro 普通用户使用说明

Squoosh Pro 是一款在 Mac 本地运行的批量图片压缩工具。图片不会上传到服务器，原图不会被覆盖。每次压缩会创建一个带时间的结果文件夹，方便查找和回退。

## 系统要求

- macOS 13 或更高版本
- Apple 芯片 Mac 或 Intel 芯片 Mac
- 建议预留足够的磁盘空间存放压缩结果

当前 Beta 安装包使用临时签名，尚未经过 Apple 公证。首次打开时，macOS 可能要求额外确认。请只从本项目的 GitHub Release 页面下载。

## 下载和安装

1. 在 GitHub Release 页面下载 `Squoosh-Pro-0.1.0-macOS-universal.zip`。
2. 双击 ZIP 文件解压。
3. 将 `Squoosh Pro.app` 拖入“应用程序”文件夹。
4. 第一次启动时，在 Finder 中右键点击 `Squoosh Pro.app`，选择“打开”，然后在系统提示中再次选择“打开”。
5. 后续可以像普通应用一样直接启动。

不需要关闭 macOS 的安全检查，也不建议运行来源不明的终端命令来绕过安全设置。

## 最快使用方法

1. 启动 Squoosh Pro。
2. 在首页选择一个压缩方案。一般网页图片可以选择“JPEG（JPG）”；网站限制单张大小时，可以选择“网页 JPEG ≤150KB”。
3. 点击“选择图片”或“选择文件夹”，也可以直接把图片拖进窗口。
4. 在左侧图片列表中点击任意图片，查看原图和输出效果。拖动预览分界线可以对比前后差异。
5. 如有需要，在右侧调整输出格式、质量、大小和图片尺寸。
6. 点击右上角“开始压缩”。
7. 完成后点击“打开输出目录”查看结果。

如果没有手动选择输出位置，应用会在原图附近创建带时间的结果文件夹。文件夹名称包含压缩时间，重复处理不会覆盖之前的结果。

## 如何选择压缩方案

### 智能推荐

适合不确定该选哪种格式时使用。应用会根据当前设置选择合适的输出方式。

### JPEG（JPG）

适合照片、商品图和大多数网站图片。JPEG 可以在 Safari、Chrome、Edge、Firefox，以及常见 Android 和 iPhone 应用中正常使用。JPEG 不支持透明背景，原图中的透明区域会自动填充为白色。

### 网页 JPEG ≤150KB

适合有单张文件大小限制的网站。此预设把 `1 KB` 按 `1000 字节` 计算，每张图片的最终文件不得超过 `150000 字节`。应用会分别检查每张图片，并在 `1000`、`960`、`920` 像素宽度中选择尽量清晰且满足大小限制的结果。

如果图片在允许的最低质量和尺寸下仍无法满足限制，该图片会显示失败，不会把超出限制的文件当作成功结果。

### 无损 PNG

适合界面截图、图标、文字较多的图片，或需要保留透明背景的图片。PNG 通常比 JPEG 大。

### 现代网站 WebP

适合支持现代图片格式的网站。通常比 JPEG 更小，也可以保留透明背景。发布前请确认目标网站或旧软件是否接受 WebP。

### 极致压缩 AVIF

适合希望进一步减小文件的场景。AVIF 压缩可能更慢，部分旧软件不支持；如果兼容性优先，建议使用 JPEG（JPG）。

## 常用设置

### 指定质量

质量数值越高，细节通常越多，文件也通常越大。照片可以先从 `75` 到 `85` 尝试，再通过预览确认效果。

### 每张不超过指定大小

输入单位为 `KB`。应用会对每张图片单独压缩并检查真实文件大小，不是按整批图片的平均值计算。

### 图片尺寸

- “保持原尺寸”：不主动改变宽度和高度。
- “最长边”：横图和竖图都以最长的一边为上限。
- “固定宽度”：按指定宽度等比例缩放，高度自动计算。
- “固定高度”：按指定高度等比例缩放，宽度自动计算。
- “适合指定范围”：完整保留图片，不裁切；宽和高都不会超过输入的范围。
- “自动选择宽度”：从预设的多个宽度中选择能满足文件大小限制的最大宽度。
- “小图片保持原尺寸”：小于目标尺寸的图片不会被放大，避免无意义的模糊和文件变大。

### JPEG 高级设置

- “渐进式显示”：网页加载时会先显示整张图片的粗略版本，再逐渐变清晰。现代主流浏览器支持此格式。
- “优化文件大小”：使用 MozJPEG 优化文件内部编码，通常可以在相同质量下减小文件，但压缩时间可能稍长。
- “标准兼容模式”：输出 Baseline JPEG，适合需要兼容非常老旧软件的情况。现代浏览器和手机通常不需要开启。

“高级设置”的展开和收起只影响设置是否显示，不会启用或停用这些设置。已经选择的选项始终会用于压缩。

## 预览、搜索和缓存

- 图片较多时，可以使用列表顶部的搜索框按文件名查找图片。
- 点击列表中的图片即可切换预览对象。
- 预览完成后，图片列表会显示“已缓存”。如果设置和原图没有变化，正式导出时会复用该结果，避免重复压缩。
- 修改压缩设置后，旧预览不会被误用。
- 缓存有数量和内存上限，不会无限增长；清空任务、完成导出或退出应用时会及时清理。

## 硬件加速预览

“设置”中的“硬件加速预览”默认开启。支持的 Mac 会使用 Metal 和 Core Image 加速预览渲染；不支持或检测到异常时，应用会自动改用兼容模式。这个开关只影响预览渲染，不会改变输出图片的质量和文件格式。

## 保存和交换自己的预设

1. 在“压缩设置”中完成调整。
2. 点击“保存为预设”。
3. 输入预设名称，并可填写用途备注。
4. 以后可以从“我的预设”中直接选择。

在“预设”页面点击“导出我的预设…”，会导出所有由用户保存的预设，不包含软件自带的系统预设。使用“导入预设…”可以在另一台 Mac 上恢复这些设置。

## 隐私和文件安全

- 所有图片都在本机处理，不需要账户，也不会上传到服务器。
- 应用不会覆盖或删除原图。
- 输出先写入临时文件，确认格式和大小有效后再保存为最终文件。
- 如果输出位置已有同名文件，应用会使用新的文件名，不会直接覆盖。
- 日志不会保存图片内容，也会避免记录完整的源文件路径。

## 校验下载文件

Release 页面同时提供 `.sha256` 文件。需要校验时，可以在“终端”中进入下载目录后运行：

```bash
shasum -a 256 -c Squoosh-Pro-0.1.0-macOS-universal.zip.sha256
```

显示 `OK` 表示下载文件与发布文件一致。

## 常见问题

### macOS 提示无法验证开发者

确认文件来自本项目 GitHub Release 页面后，在 Finder 中右键点击应用，选择“打开”，再确认一次。不要关闭整个系统的安全保护。

### 为什么某张图片没有达到目标大小

为了避免输出无法使用的图片，应用设置了最低质量和允许的尺寸范围。如果仍无法满足目标，该图片会明确标记为失败。可以提高目标 KB、允许更小的尺寸，或改用 WebP/AVIF 后重试。

### 为什么预览大小和导出大小有时会变化

只要原图和设置没有变化，已缓存预览会直接用于导出。修改格式、质量、尺寸或高级设置后，应用会重新计算，文件大小也会随之变化。

### 为什么 AVIF 比 JPEG 慢

AVIF 的编码计算量通常更高，尤其是大尺寸图片。兼容性或速度优先时，建议使用 JPEG（JPG）。

### Intel Mac 能否使用

安装包同时包含 Apple 芯片和 Intel 的可执行代码。当前版本已完成通用二进制构建检查，但发布前没有在真实 Intel Mac 上完成运行测试，因此仍将其标记为 Beta 版本。
